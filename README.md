# Billionaire Brawl

A satirical Street Fighter-style 1v1 fighter. Roster is the Forbes top ten richest people as of **1 August 2026, 12:00 a.m. ET**.

Open `index.html` from disk (`file://`). No build step.

```
npm test
```

Quality bar: `BAR.md` and `refs/stills/`. Lead prompt: `PROMPT.md`. Live loop: `progress.html`.
